Dependency-free tiny utility

日本語フォーム入力の
表記ゆれを安全に正規化。

全角数字、全角英字、全角スペース、ハイフン類をフォーム入力向けに扱いやすく整える TypeScript utility です。

Get started Try demo 
import { normalizeJaInput } from "normalize-ja-input"

normalizeJaInput("　ＴＥＬ：０９０ー１２３４ー５６７８　")
// "TEL：090-1234-5678"

Form focused

                
電話番号、氏名、住所、IDなどの入力前処理に使いやすい小さな設計。

              

            

            

              

                
Configurable

Zero dependencies

                
Node.js、ブラウザ、フロントエンドフォームで扱いやすい依存ゼロ構成。

              

            

          

        

      


      

        

          

            

              
Install

              
npmでインストールして、TypeScript/JavaScriptから利用できます。

            

            

              

                
npm install normalize-ja-input

              

              

                
import { normalizeJaInput } from "normalize-ja-input"

const value = normalizeJaInput("　ＡＢＣー１２３　")
// "ABC-123"

              

            

          

        

      


      

        

          

            

              
API

            

            

              

                
import { jaInputPresets, normalizeJaInput, normalizeJaInputWithChanges } from "normalize-ja-input"

normalizeJaInput("やまだ　ﾀﾛｳ", {
  ...jaInputPresets.furigana,
  kanaScript: "katakana",
})
// "ヤマダ タロウ"

normalizeJaInputWithChanges("　０９０ー１２３４　", jaInputPresets.phone)
// { value: "090-1234", changes: ["spaces", "digits", "hyphens", "trim"] }

normalizeJaInput(input: string, options?: {
  trim?: boolean
  lineEndings?: "preserve" | "lf"
  trimLines?: boolean
  collapseSpaces?: boolean | "horizontal"
  spaces?: "preserve" | "halfwidth" | "ascii"
  digits?: "preserve" | "halfwidth"
  alphabets?: "preserve" | "halfwidth"
  katakana?: "preserve" | "fullwidth"
  kanaScript?: "preserve" | "hiragana" | "katakana"
  kanaMarks?: "preserve" | "compose"
  hyphens?: "preserve" | "ascii" | "between-digits"
  punctuation?: "preserve" | "ascii"
}): string

              

            

          

        

      


      

        

          

            

              
CDN

              

                npmで公開されたパッケージを、ブラウザからESモジュールとして読み込めます。
              

            

            

              

                
<script type="module">
  import { normalizeJaInput } from "https://unpkg.com/normalize-ja-input/dist/index.js"

  console.log(normalizeJaInput("　ＡＢＣー１２３　"))
</script>
